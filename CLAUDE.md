# Darts – notes for Claude Code

Darts is a free, offline darts scorer: X01, Cricket, Killer, Around the Clock, Shanghai, Bob's 27 and practice drills,
with a CPU opponent (10 levels named after champions), voice caller, voice scoring and detailed statistics.
It ships as an Android APK (Capacitor 8) and as an installable web app for iPhone (GitHub Pages).

## Layout

- `www/index.html` – the whole app: HTML, CSS and JS in one file. UI strings live in `STR.it` and `STR.en`; `t(key, ...args)` resolves them.
- `www/audio/<it|en>/` – recorded caller clips (Opus `.ogg`) plus `clips.json` (clip name → duration in seconds).
- `www/sw.js`, `www/manifest.webmanifest`, `www/icons/` – web app (offline cache, Home screen install).
- `.github/workflows/build-apk.yml` – builds and signs the APK; `web-app.yml` – publishes `www/` to GitHub Pages.
- `assets/` – icons and splash screens for the Android build.

## Branches, builds and releases

- Work on the `test` branch. A push to `test` builds an APK artifact (`darts-dev.N`) without publishing anything.
- Merge `test` into `main` and create a tag `vX.Y.Z` only when the owner confirms the build is stable.
  A tag publishes the GitHub Release with `darts.apk` and updates the iPhone web app. Never tag on `test`.
- `APP_BUILD` and `SW_VERSION` stay `'dev'` in the source: the workflows stamp the version from the tag.
- Signing uses the secrets `ANDROID_KEYSTORE_BASE64` and `ANDROID_KEYSTORE_PASSWORD` (key alias `darts`); keep the same key,
  or installed copies can no longer be updated.
- The `github-pages` environment allows deployments from `main` and tags `v*`.
- README, docs, LICENSE and every file in the repository are written in English.

## Product rules

- The app is bilingual, Italian and English. Every new string exists in both languages; translations are natural, never literal,
  and texts are short. Italian caller phrase: "Ti mancano N punti".
- Game title shows only the game type (e.g. "501 – double out"). Default entry is one dart at a time.
- All players, scores and checkout suggestions stay visible without scrolling on every screen from 320×480 to 800×1280.
  Popups are centred.
- Keep the app lean and responsive without losing quality or effects: no new dependencies unless needed, measure render cost.
- For visible changes, show a mockup first when possible.

## Behaviour worth knowing

- Visit limit (X01 "Max visits"): if nobody checks out by the last visit, the match is void and nothing is saved
  (`G.void`, window with Play again / Back to home / Undo last dart).
- Recorded caller: `say()` takes segments `{t, c, opt}`; `c` is a clip name. If any required clip is missing the whole call
  falls back to the phone's text-to-speech; an `opt` segment without a clip is skipped. Clips never contain player names.
  Clips are generated by the owner with ElevenLabs.
- Italian bust exclamations rotate at random; "Porco dio" only when Settings → "Esclamazioni volgari (NSFW)" is on.
- Voice scoring uses `@capgo/capacitor-speech-recognition`. "Always listening" keeps one segmented session open for the match,
  ignores results while and just after the caller speaks, and falls back to online recognition if the offline model is missing.
  The workflow adds the `RecognitionService` query to the Android manifest.

## Before every push to `test`

- Italian and English: no string of one language on screens of the other.
- Layout: every game mode, 1–8 players, teams, total entry and open popups, on 320×480 up to 800×1280, in both languages.
- Regression: full CPU-vs-CPU matches in every mode, undo, history/statistics, backup restore.
- Voice features can only be partly tested in a browser; say what the owner must try on the phone.
